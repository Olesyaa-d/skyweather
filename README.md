# ☀️ SkyWeather

**SkyWeather** — мобильное приложение для просмотра актуальной погоды в городах по всему миру, разработанное на Flutter.

Приложение позволяет быстро узнать температуру воздуха, влажность, скорость ветра и текущие погодные условия. Интерфейс дополняется анимированным фоном, который меняется в зависимости от погоды.

## 📱 Возможности

- 🌡️ **Текущая погода** — отображение температуры, влажности, скорости ветра и погодных условий.
- 🌤️ **Анимированный фон** — визуальные эффекты солнца, облаков, дождя, снега, грозы и тумана.
- 🔎 **Поиск городов** — поиск населённых пунктов с подсказками по мере ввода.
- ⭐ **Избранные города** — добавление и удаление городов из сохранённого списка.
- 💾 **Локальное хранение** — сохранённые города остаются в приложении после перезапуска.
- 🌐 **Актуальные данные** — получение информации о погоде через Open-Meteo API.
- 📱 **Удобный интерфейс** — простая навигация между экранами.

## 🚀 Установка и запуск

### Требования

Для запуска проекта необходимы:

- Flutter SDK
- Dart SDK
- Android Studio или Visual Studio Code
- Android-эмулятор или физическое Android-устройство
- Подключение к интернету для получения погодных данных

### 1. Получение проекта

Склонируйте репозиторий:

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd skyweather
```

Либо откройте папку проекта в Visual Studio Code.

### 2. Установка зависимостей

```bash
flutter pub get
```

### 3. Запуск приложения

Подключите Android-устройство или запустите эмулятор.

Проверьте доступные устройства:

```bash
flutter devices
```

Запустите приложение:

```bash
flutter run
```

## 🧪 Тестирование

Для запуска автоматизированных тестов:

```bash
flutter test
```

Для проверки проекта анализатором Dart:

```bash
flutter analyze
```

## 🌍 Источник данных

SkyWeather использует бесплатный сервис [Open-Meteo](https://open-meteo.com/).

Приложение обращается к API для получения:

- текущей температуры воздуха;
- относительной влажности;
- скорости ветра;
- погодных условий;
- информации о городах при поиске.

Для получения актуальной погоды необходимо подключение к интернету.

## 🎨 Анимация погодных условий

Одна из особенностей SkyWeather — динамический погодный фон.

В зависимости от полученных данных приложение отображает разные визуальные эффекты:

| Погода | Эффект |
|---|---|
| ☀️ Ясно | Солнце |
| ☁️ Облачно | Движущиеся облака |
| 🌧️ Дождь | Падающие капли |
| ❄️ Снег | Падающие снежинки |
| ⛈️ Гроза | Грозовые эффекты |
| 🌫️ Туман | Туманная атмосфера |

Анимации реализованы средствами Flutter без подключения отдельного анимационного движка.

## 🧭 Основные экраны

### Главный экран

Показывает текущую погоду выбранного города, основные метеорологические показатели и анимированный фон.

### Список городов

Отображает сохранённые пользователем города и позволяет управлять списком.

### Добавление города

Позволяет найти город через поисковую строку с подсказками и добавить его в сохранённый список.

## 🔒 Хранение данных

Список городов сохраняется локально с помощью `shared_preferences`.

Для работы с погодными данными приложение выполняет сетевые запросы к Open-Meteo. Секретные API-ключи для этого не требуются.
